# ADR-001: Adopt a Layered Microservice Architecture with React Native, Node.js and Polyglot Persistence

## Status
Accepted

## Context
FitFlow must rapidly rebuild user trust and reverse retention drop-off by delivering AI-personalized workouts, private social circles, and camera-based nutrition tracking on a mid-sized startup budget, while strictly complying with GDPR/CCPA standards.

## Decision
We adopt Stack A:
- **Frontend:** React Native (iOS & Android) with native modules for camera & TFLite.
- **Core API:** Node.js with Express exposing REST & WebSockets.
- **AI Microservice:** Python with FastAPI for computer vision and dynamic workout modeling.
- **Persistence:** Polyglot layer using PostgreSQL (health logs) and Firebase Firestore (real-time community).
- **Authentication:** Firebase Auth.

## Consequences
- **Positive:** Faster MVP delivery, single-language team synergy, isolated heavy AI workloads, clear compliance boundaries.
- **Negative:** Managing two database paradigms (PostgreSQL + Firestore) increases operational complexity.
